# 개발 준비 템플릿의 참고 기준

[템플릿 목차](README.md) · [실제 요청문](request-template.md)

확인일은 **2026-09-30**입니다. 아래는 발행 기관의 공식 페이지에서 확인한 자료입니다. 국제표준, 정부 지침, W3C 권고안, 민간 공개 표준과 실무 템플릿을 구분합니다. 마지막 열은 발행 기관의 요구를 그대로 옮긴 것이 아니라 **빌드브리프의 활용 방안**입니다.

## 국제표준

ISO 자료는 공식 발행 정보와 공개 초록으로 적용 범위를 확인했습니다. 표준 전문을 조항별로 검토하거나 서식을 복제하지 않았으며, 다음 연결은 적합성 심사용 조항 매핑이 아닙니다.

[SSDF 1.2 / SP 800-218 Rev.1](https://csrc.nist.gov/pubs/sp/800/218/r1/ipd)는 2025-12-17 공개된 초기 초안입니다. 현재 기준 목록의 확정본을 대체한 것으로 취급하지 않습니다. 새 판을 채택할 때는 해당 시점의 공식 상태를 다시 확인합니다.

비밀번호 저장 방식의 세부 설명은 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)를 보충 자료로 확인했습니다. 직접 저장이 필요한 경우의 비밀번호 해싱과 salt·계산 비용 검토를 참고하며, 로그인 기능이 없는 제품에 비밀번호 저장을 추가하는 근거로 사용하지 않습니다.

## 이 자료를 근거로 말할 수 있는 범위

- 템플릿은 위 기준의 목적과 적용 범위를 참고한 독자적인 요청문입니다. 표준 원문, 공식 번역, 인증된 서식 또는 전문 조항 체크리스트가 아닙니다.
- 템플릿 사용만으로 ISO·ASVS·WCAG 준수나 서비스 보안을 보증하지 않습니다. 실제 적용 범위, 검토자, 검증 방법과 결과가 별도로 필요합니다.
- ASVS·WCAG의 정확한 항목 번호를 인용할 때는 지정 버전의 실제 원문을 확인합니다. 전체 범위를 점검하지 않았다면 전수 검증이라고 쓰지 않습니다.
- ISO 29110의 소규모 개발 관점은 참고할 수 있지만 의료·안전 필수·기타 규제 제품의 전문 검토를 대체하지 않습니다.
- Docker, MSA, DDD, FSD, Git 버전 형식, 특정 언어·프레임워크·AI 스킬은 위 표준이 공통으로 의무화하는 기술 목록이 아닙니다.

## 개발 AI의 읽기 경로

[OpenAI AGENTS.md 안내](https://learn.chatgpt.com/docs/agent-configuration/agents-md)는 Codex의 프로젝트 지침 파일 탐색을 설명합니다. `AGENTS.md`의 명시적 지시로 `ROOT.md`를 읽게 하는 것은 빌드브리프가 선택한 프로젝트 구성입니다. 모든 AI가 두 파일이나 외부 링크를 자동으로 읽는다고 보장하지 않습니다. 이 문서는 개발 표준 11개와 별개인 도구 사용 근거입니다.

[ROOT.md 원형](ROOT.template.md)에 작업 조건과 직접 연결된 공식 URL을 모았습니다. 추가한 OWASP Cheat Sheet, PostgreSQL, Docker 문서는 구현 자료이며 ISO와 같은 국제표준으로 분류하지 않습니다. PostgreSQL 18과 Docker 링크는 선택한 기술이 해당할 때의 예시입니다. 생성할 프로젝트에서 확인한 버전에 맞게 구체화하고 URL 열람과 실제 코드 검증의 기록을 분리합니다.

## 재사용과 유지보수

업무 실행 지침의 보완에는 [김스듴의 AI 위임 루프](https://sdk-kim-builds.com/guides/ai-delegation-loop-playbook/)를 2026-10-02에 참고했습니다. 개인의 실무 가이드이며 공인 개발 표준으로 분류하지 않습니다. 절차·재사용 자료·검증 근거를 연결하고 실패 원인을 다음 작업 지침에 반영하는 관점을 빌드브리프의 기존 문서 구조에 맞게 정리했습니다. 원문의 프롬프트·고정 질문 수·파일 구성은 복제하지 않았으며, 글에서 소개한 타사의 성과를 이 템플릿의 효과로 주장하지 않습니다.

표준·외부 템플릿 원문을 저장소에 포함하지 않았습니다. 요약과 공식 링크를 관리하며, 원문이나 서식의 직접 재사용은 해당 이용 조건을 따로 확인합니다. 특히 [arc42의 라이선스 안내](https://faq.arc42.org/questions/A-2/)는 템플릿 구조와 설명에 CC BY-SA 4.0을 적용합니다. 참고 링크를 제공하는 것과 템플릿을 복제·수정해 배포하는 것은 구분합니다.

버전 변경 시 발행 상태, 적용 범위, 기존 판과의 차이, 요청문에 미치는 영향을 검토합니다. 초안·철회판·확정판을 섞지 않고 확인 날짜와 URL을 함께 갱신합니다. 표준을 더 수집하는 경우에는 먼저 현재 검토 항목의 어떤 공백을 채우는지 설명합니다.
