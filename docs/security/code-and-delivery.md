# 코드·배포·공급망·오류

[보안 목차](../../SECURITY.md) · [적용 범위·상태 기준](scope.md) · [검증 절차·이력](verification.md)

공개 파일·실행 코드·의존성·CI 권한·비밀값·오류 처리·회귀 검사를 바꿀 때 읽습니다. 담당 항목: **BB-18~22**.

담당: 변경을 만드는 개발자와 검토자. 점검 상태는 기재한 검증 범위에 한정하며, ASVS 전체 충족을 뜻하지 않습니다.

관련 코드: [release.yml](../../.github/workflows/release.yml), [build.cjs](../../scripts/build.cjs), [release.cjs](../../scripts/release.cjs), [check.cjs](../../check.cjs), [check-runtime.cjs](../../scripts/check-runtime.cjs), [app.js](../../dist/app.js), [storage.js](../../dist/storage.js), [.gitignore](../../.gitignore).
