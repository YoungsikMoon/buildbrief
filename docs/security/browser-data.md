# 브라우저·통신·자료 보호

[보안 목차](../../SECURITY.md) · [적용 범위·상태 기준](scope.md) · [검증 절차·이력](verification.md)

CSP·보안 헤더·외부 링크, 브라우저 저장·백업의 기밀성, 복사·공유·삭제 범위를 바꿀 때 읽습니다. 담당 항목: **BB-11~17**.

담당: 변경을 만드는 개발자와 검토자. 점검 상태는 기재한 검증 범위에 한정하며, ASVS 전체 충족을 뜻하지 않습니다.

관련 코드: [_headers](../../dist/_headers), [index.html](../../dist/index.html), [app.js](../../dist/app.js), [storage.js](../../dist/storage.js), [projects.js](../../dist/projects.js). 실제 호스팅·도메인 설정은 [운영 점검표](operations.md)의 OPS-04에서 확인합니다.

## 점검표

| ID · ASVS 참조 | 확인할 사항 | 상태 | 근거와 남은 확인 |
| --- | --- | --- | --- |
| BB-11 · `v5.0.0-3.4.3`, `v5.0.0-3.4.6` | CSP로 허용한 자체 리소스만 읽고, 인라인 코드·객체·프레임·워커·폼 전송·앱 네트워크 연결 제한. 다른 사이트의 프레임 삽입 차단. | 확인 | `dist/_headers`, 지시문 전체 비교 검사, 배포 응답 확인. `unsafe-inline`·`unsafe-eval` 없음. CSP는 출력 인코딩을 대신하지 않습니다. |
| BB-12 · `v5.0.0-3.4.4`, `v5.0.0-3.4.5` | MIME 추측 방지와 참조 주소 미전송, 새 탭 링크의 원래 창 접근 방지. | 확인 | `nosniff`, `no-referrer`, `target="_blank"`의 `noopener noreferrer` 검사. 카메라·마이크·위치는 Permissions Policy로 차단합니다. |
| BB-13 · `v5.0.0-3.4.1`, `v5.0.0-12.1.1`, `v5.0.0-12.1.2` | HTTPS, 인증서, TLS 버전·암호 설정, HTTP 리다이렉트, 오류 응답에도 필요한 헤더 적용. | 부분 | 운영 페이지의 HTTPS 응답과 1년 HSTS는 확인했습니다. 구형 TLS 차단·암호 목록·인증서 갱신·대체 주소·오류 응답은 미점검입니다. `includeSubDomains`·preload는 전체 도메인 영향을 확인하지 않고 켜지 않습니다. |
| BB-14 · `v5.0.0-14.1.1`, `v5.0.0-14.1.2` | 아이디어·개인정보·비밀값의 민감도를 정하고 저장·공유·보관·삭제 요구사항 명시. | 부분 | [적용 범위](scope.md)에 보호 대상을 적었지만 민감도별 허용 범위·보관 기간·보호 수단은 확정되지 않았습니다. 기밀 아이디어까지 보호한다고 안내하기 전에 정해야 합니다. |
| BB-15 · `v5.0.0-14.3.3`, `v5.0.0-14.2.4` | 민감한 자료를 브라우저 저장·백업에 평문으로 두는 위험과 필요한 보호 수단 확인. | 부분 | 현재 암호화·사용자별 접근 통제는 없습니다. 비밀값 입력 금지 안내는 보호 기능이 아닙니다. 같은 기기를 쓰는 사람·확장 프로그램·악성 같은 출처 코드로부터 기밀성을 보장하지 않습니다. |
| BB-16 · `v5.0.0-14.2.3` | 답변이 분석 도구·외부 AI·제3자에게 자동 전송되지 않음. 복사·내보내기 전에 이용자가 전달 범위를 확인할 수 있음. | 확인 | 현재 실행 코드에 외부 수집·AI API 호출 없음, CSP `connect-src 'none'`, 초안 미리보기 제공. 이용자가 직접 누른 외부 링크와 붙여 넣기까지 차단하는 기능은 아닙니다. URL 쿼리·메모의 비밀값 자동 탐지도 없습니다. |
| BB-17 · `v5.0.0-14.1.2`, `v5.0.0-14.2.4` | 프로젝트 삭제와 복구의 범위를 설명하고, 내려받은 백업·클립보드·외부 AI 사본까지 삭제됐다고 오해시키지 않음. | 부분 | 브라우저 프로젝트 삭제·백업 기능은 있으나 전체 사본 삭제와 복구 정책 검토는 남았습니다. 서비스에서 프로젝트를 삭제해도 내려받은 파일이나 외부 전달 사본은 남습니다. |

입력·백업의 형식 검증은 [입력·출력·백업](input-output.md), 서버 저장·암호화·외부 전송 도입은 [기능 확장](feature-changes.md)을 함께 검토합니다.
