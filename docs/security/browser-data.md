# 브라우저·통신·자료 보호

[보안 목차](../../SECURITY.md) · [적용 범위·상태 기준](scope.md) · [검증 절차·이력](verification.md)

CSP·보안 헤더·외부 링크, 브라우저 저장·백업의 기밀성, 복사·공유·삭제 범위를 바꿀 때 읽습니다. 담당 항목: **BB-11~17**.

담당: 변경을 만드는 개발자와 검토자. 점검 상태는 기재한 검증 범위에 한정하며, ASVS 전체 충족을 뜻하지 않습니다.

관련 코드: [_headers](../../dist/_headers), [index.html](../../dist/index.html), [app.js](../../dist/app.js), [storage.js](../../dist/storage.js), [projects.js](../../dist/projects.js). 실제 호스팅·도메인 설정은 [운영 점검표](operations.md)의 OPS-04에서 확인합니다.

## Cloudflare 방문·성능 통계

2026-10-20 기준 [Web Analytics는 무료](https://developers.cloudflare.com/web-analytics/about/)이며 별도 유료 상품·SDK·사용자 행동 이벤트를 추가하지 않습니다. [공식 RUM 설명](https://developers.cloudflare.com/speed/observatory/rum-beacon/)에 따르면 쿠키·localStorage·sessionStorage·IndexedDB를 읽거나 저장하지 않으며 페이지 주소·유입 경로·방문·성능 정보를 처리합니다. Cloudflare가 자동 삽입한 SRI 적용 스크립트를 사용하고 앱에서 복제하지 않습니다. IP 주소는 HTTP 처리 과정에서 수신되므로 개인정보가 전혀 처리되지 않는다고 표현하지 않습니다.

CSP 예외는 `https://static.cloudflareinsights.com/beacon.min.js` 및 그 버전 하위 경로, `https://buildbrief.moon0sik.cloud/cdn-cgi/rum`만 허용합니다. `connect-src self`나 임의의 외부 도메인을 열지 않습니다. 작성한 답변·프로젝트·백업·복사한 프롬프트는 수집 대상이 아닙니다. URL에 비밀값을 넣지 않으며, 서비스도 답변을 URL에 저장하지 않습니다. 차단 도구나 수집 장애가 있어도 기획·저장·백업은 독립적으로 동작해야 합니다.

외부 스크립트는 페이지 권한을 공유합니다. 공급자의 자동 업데이트를 신뢰하는 구조이며, 현재 전송 검증으로 이후 모든 버전의 동작을 보장하지 않습니다. 공급자·수집 항목·가격·SRI가 달라지거나 통계가 불필요해지면 이 CSP 예외를 제거하고 자동 삽입도 끕니다.

## 개발·테스트 제외 경계

`analytics-preferences.js`는 첫 번째 동기 스크립트입니다. `?analytics=off`는 `buildbrief-analytics-excluded=1`이라는 운영자 통계 제외 설정만 이 브라우저에 저장하고 `on`은 제거합니다. 이 값은 개인 식별이나 추적에 사용하지 않습니다. 중복·알 수 없는 쿼리 값은 무시하고 다른 쿼리·hash·history 상태와 프로젝트 자료는 보존합니다.

제외 표시·navigator.webdriver·비운영 호스트·저장소 오류가 있으면 head에 추가 CSP를 적용해 Cloudflare 스크립트와 통계 연결을 차단합니다. HTTP CSP를 완화하거나 Cloudflare 전체 계정 설정을 바꾸지 않습니다. 제외 브라우저의 정확한 통계 스크립트 차단 콘솔은 예상 동작이며, 일반 방문자 수집과는 구분합니다. 다른 기기·프로필·시크릿·저장소 삭제 후에는 제외 설정이 이어지지 않습니다.

자체 브라우저 검사는 통계 POST를 항상 로컬 204 응답으로 처리해 실제 집계에 보내지 않습니다. 일반 방문 경로 시험에서만 자동화 표시를 합성한 보통 방문자로 바꾸고, 그 경우에도 실제 전송은 하지 않습니다. 표준 자동화 표시를 숨긴 다른 도구까지 완전히 식별하지는 않습니다. 과거 익명 집계와 이전 탭의 이탈 보고를 소급 제거하지 않습니다.
