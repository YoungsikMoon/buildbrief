# 사용 가이드

[프로젝트 안내·문서 목차](../README.md) · [저장과 백업](storage-and-backup.md)

서비스를 처음 사용하거나 질문 흐름·기획 초안·AI 전달문·진행률의 동작을 확인할 때 읽습니다. 화면 크기와 스타일 기준은 [UI 기준](ui-guidelines.md)에서 관리합니다.

## 무엇을 만들 수 있나요?

1차 목표는 **아이디어를 구체화하는 데 필요한 정보를 정리하는 것**입니다. 필요한 기능과 화면을 연결하고, 떠오르는 생각과 궁금한 점을 담은 기획 초안을 만듭니다. 처음 만들 범위와 아이디어를 확인할 방법은 이 초안을 사람 또는 AI와 다듬으며 정할 수 있습니다.

| 결과물 | 담기는 내용 | 사용하는 방법 |
| --- | --- | --- |
| 서비스 기획 초안 | 입력한 답변, 기능·화면 연결, 선택 이유, 미정 사항 | 화면에서 확인하거나 Markdown 파일로 내려받기 |
| AI에게 전달할 요청문 | 기획 초안과 보완 지침, 비교·추천을 요청한 질문 | ‘AI와 기획 다듬기 · 복사’ 후 원하는 AI 대화에 붙여 넣기 |
| 프로젝트 백업 | 답변·메모·추천 요청·작성 단계 등 프로젝트 기록 | JSON 파일로 보관하고 ‘백업 불러오기’로 불러오기 |

사이트에서 AI를 자동 실행하거나 코드를 생성하지 않습니다. 기술 스택도 자동 확정하지 않습니다. AI 전달문은 바로 개발하기보다 빠진 정보와 모순을 확인하고 기획을 보완하도록 안내합니다. 브라우저에서 복사가 허용되지 않으면 요청문을 Markdown 파일로 내려받습니다.

## 시작 안내

작성 페이지는 제목·짧은 설명 아래에서 바로 질문을 시작합니다. 현재 위치는 **다음 단계** 버튼 안의 **1 / 6** 표시로 확인하며, 마지막 단계에서는 **기획 초안 보기 6 / 6 →**로 바뀝니다. 좌측 **내 프로젝트** 옆의 아이콘이 있는 **관리** 버튼에서 프로젝트 관리 창을 엽니다.

첫 화면에서 회원가입 없이 시작할 수 있다는 점, 답변의 브라우저 저장, 직접 선택하는 AI 공유, 파일 백업을 확인할 수 있습니다. 소개 아래의 BEFORE → AFTER에서는 산책 모임·공방 예약·재료로 요리 찾기, 세 가지 아이디어가 서비스 화면과 구체적인 문제·사용자·첫 기능·선택 이유로 정리되는 모습을 볼 수 있습니다. 위쪽의 좌우 버튼을 누르거나 모바일에서 옆으로 밀어 다른 예시를 보세요. 목록에 키보드 초점을 두면 좌우 방향키, Home/End로도 이동할 수 있습니다. 가상 기획과 디자인이며 실제 출시 사례나 내 답변에서 자동 생성된 결과가 아닙니다. 예시를 둘러봐도 내 프로젝트 내용은 바뀌지 않습니다.

처음 방문하면 **00 시작 안내**에서 아이디어가 기획 초안으로 정리되는 예시를 바로 볼 수 있습니다. ‘바로 시작하기’로 01 단계에 진입하거나, **‘사용 가이드 자세히 보기’**를 펼쳐 프로젝트 준비 → 질문 작성 → 초안 확인 → AI 요청문 복사 → 외부 AI와 보완 → 백업·이어쓰기의 6단계를 화면 예시와 함께 따라갈 수 있습니다. 실제 버튼 이름, PC·모바일에서의 위치, 프로젝트 관리, 복원용 JSON 백업과 공유용 기획 초안의 차이를 안내합니다. 예시는 가상 프로젝트이며 내 답변에 추가되지 않습니다.

사이트 링크를 열거나 새로고침하면 기존 작성 여부와 관계없이 **00 시작 안내**를 먼저 보여 줍니다. 저장된 프로젝트·답변·메모·작성 단계는 그대로 보존합니다. ‘바로 시작하기’를 누르면 01로 이동하고, 목차에서 원하는 단계로 바로 이동할 수도 있습니다. 서비스 안에서 프로젝트를 전환하면 해당 프로젝트의 마지막 작성 단계가 열리며, 새 프로젝트는 01부터 시작합니다. 안내는 상단 로고나 왼쪽 목차에서 언제든 다시 열 수 있으며 질문 수와 진행률에는 포함되지 않습니다.

## 6단계 작성 흐름

순서대로 작성하거나 왼쪽 목차에서 필요한 단계로 이동할 수 있습니다. 모든 질문을 한 번에 채울 필요는 없습니다.

| 단계 | 주제 | 정리하는 내용 |
| --- | --- | --- |
| 01 | 아이디어 소개 | 프로젝트 이름, 누구에게 무엇을 제공할지 |
| 02 | 문제와 기존 방법 | 불편한 상황, 현재 해결 방식, 바라는 변화 |
| 03 | 사용할 사람과 환경 | 첫 사용자, 이용 상황·기기, 로그인 여부·방식, 역할 목록 |
| 04 | 참고 서비스와 디자인 방향 | 참고 URL, 화면 분위기, 기존 브랜드 자료 |
| 05 | 화면과 기능 | 기본 공통 화면 → 개별 화면 → 요소 배치 → 기능·동작 |
| 06 | 마무리 메모 | 남기고 싶은 생각이나 궁금한 점 (선택) |

예약·결제·알림 같은 기능과 처리 조건도 관련 화면 요소의 설명에 함께 적습니다. 별도의 ‘화면 밖 기능’ 질문이나 기능별 후속 질문은 제공하지 않습니다. 이전에 따로 적은 기능·규칙·선택 이유는 초안의 ‘이전에 작성한 내용’과 백업에 보존하며 현재 진행률에는 포함하지 않습니다. 모르는 내용은 비워 두고 넘어가도 됩니다. 빈칸은 확정된 선택을 뜻하지 않습니다.

06의 마무리 메모는 비워 두고 **‘기획 초안 보기’**로 넘어가도 됩니다. 작성한 내용만 초안에 담고, 빈 메모를 미정 질문으로 다시 요구하지 않습니다. 첫 출시 범위와 아이디어의 쓸모를 확인하는 방법은 ‘AI와 기획 다듬기 · 복사’에 후속 제안 요청으로 포함합니다. 이전 질문지에서 작성한 제외 범위·검증 방법·범위 판단 이유는 초안의 ‘이전에 작성한 내용’과 백업에 보존합니다.

## 화면을 구성하는 방법

1. 05 화면·기능에서 **기본 공통 화면**을 선택합니다. 상단·왼쪽·본문·오른쪽·하단·화면 위에 겹쳐 표시 중 원하는 구역 이름 바로 오른쪽의 **+**를 누르면 빈 요소 박스가 생깁니다. 요소 종류를 먼저 선택하지 않습니다.
2. 오른쪽 **설정**에서 **요소 이름**과 **어떤 용도로 쓰나요?**를 적습니다. 보여 줄 정보, 필요한 버튼·입력 항목, 가능한 기능, 눌렀을 때의 결과를 자연어로 함께 적어도 됩니다. 모르는 내용은 비워 두어도 됩니다.
3. 설정의 **?**를 누르면 오른쪽에 참고 자료가 열립니다. **참고할 분류**에서 화면 요소의 종류나 **기능 살펴보기**를 선택합니다. 이미지·이름을 누르면 자세한 설명과 예시가 열립니다. **설정으로** 돌아와 입력을 이어가세요. 참고 자료를 눌러도 요소나 기능을 자동 추가하지 않고 기존 입력도 바꾸지 않습니다.
4. 박스 오른쪽 아래 손잡이를 끌어 너비와 높이를 조절합니다. 손잡이에 키보드 초점을 두고 좌우 방향키로 너비, 위아래 방향키로 높이를 바꿀 수도 있습니다. 포인터 조절 중 Escape를 누르면 취소됩니다. PC에서는 박스를 다른 구역이나 요소 안으로 끌어 옮길 수 있고, **앞으로·뒤로**로 같은 위치 안의 순서를 정합니다.
5. 요소 이름 바로 오른쪽의 **+**는 그 요소 안에 새 요소를 만듭니다. 안에 요소가 없으면 추가용 빈 줄이나 구분선을 표시하지 않습니다. 오른쪽 **+ 요소 추가**는 선택한 요소와 같은 위치에 추가하며, 선택한 요소가 없으면 본문에 추가합니다. 휴지통 버튼으로 삭제하고, 상위 요소를 삭제해도 그 안에 있던 다른 요소는 밖으로 옮겨 보존합니다.
6. **+ 새 화면**으로 개별 화면을 만듭니다. 공통 요소는 옅게 표시되고 선택하면 공통 화면에서 수정합니다. 개별 화면에서 공통 요소 이름 옆의 **+**를 누르면 해당 화면에만 필요한 요소를 넣습니다. **화면 설정**에서는 이름·목적·역할·공통 틀 사용 여부를 정합니다. 각 화면의 선택 이유는 가운데 화면 아래에 따로 남깁니다.

각 구역과 요소 내부에는 격자가 있습니다. 이름을 끌면 놓을 위치가 표시되고, 놓은 위치는 자동 저장됩니다. 설정의 **위치 방향 버튼**으로도 위·아래·좌우로 옮길 수 있습니다. **너비 → 절반**으로 줄이면 옆에 다른 요소를 놓기 쉽습니다. 겹치는 요소는 다음 빈 줄로 이동하며, 개별 화면의 공통 요소는 원래 위치를 유지합니다. 격자 위치는 초안과 백업에도 포함됩니다.

**크게 보기**를 누르면 메뉴와 페이지 여백을 숨기고 편집기를 창 전체로 넓힙니다. **작게 보기** 또는 Escape로 돌아옵니다. 도움말이나 크기 조절 중에는 Escape가 먼저 해당 작업을 닫거나 취소합니다. 좁은 화면에서는 캔버스 안을 가로로 스크롤할 수 있습니다.

PC에서는 **설정 패널 왼쪽 화살표**로 접고 펼칩니다. 접으면 배치 화면이 넓어지고, 오른쪽에 남은 화살표로 다시 열 수 있습니다. 모바일에서는 패널 위의 **설정 접기 / 펼치기**를 누릅니다. 접었다 열어도 편집 중인 요소와 참고 자료의 분류는 유지됩니다. 화면 선택 탭이 길면 좌우로 스크롤합니다. 배치한 박스에는 이름만 표시하고, 설명은 박스를 선택한 뒤 설정 패널에서 확인·수정합니다. 모바일에서는 배치 화면 아래에 설정 패널이 열립니다. 이름과 설명은 요소마다 따로 저장하므로 같은 종류의 폼이나 표도 여러 박스로 나눠 적을 수 있으며, 설명은 초안·백업에도 포함됩니다.

크기는 기획용입니다. 너비는 부모 요소나 구역의 20~100%이며, 높이는 64px까지 줄이거나 800px를 넘어 늘릴 수 있습니다. 이름·조작 버튼·안에 넣은 요소가 잘리지 않도록 필요한 높이는 확보합니다. 작은 구역에서는 읽을 수 있는 최소 폭을 확보합니다. 실제 제품의 픽셀 크기나 반응형 규칙을 확정하는 도구는 아닙니다. 기존 질문지에서 작성한 폼·표 항목, 기능·동작, 메모·추천 요청은 새 화면 편집 방식에서도 기획 초안과 백업에 보존됩니다.

초안에서는 삭제된 기능의 연결 번호와 작성 내용이 없는 예전 기능 카드를 제외합니다. 이름 없이 설명·메모·추천 요청을 남겼다면 그 내용은 표시하며, 연결이 없어져도 직접 적은 동작은 유지합니다. 이 정리는 초안·AI 복사·파일 내려받기에만 적용하고 저장 원본과 백업을 지우지 않습니다.

## 주요 기능

- **기존 기획 보존**: 이전에 구조화해 적은 폼·표 항목, 공유 기능, 동작·오류 대응과 추천 요청은 초안·백업에 연결을 유지합니다. 새 기획에서는 알림·처리 기능까지 관련 요소의 자연어 설명에 함께 적습니다.
- **화면 요소 구체화**: 구역에 빈 박스를 만들고 이름과 용도·기능·동작을 내 말로 적습니다. 폼 항목, 표의 열, 버튼의 동작도 같은 설명에 적을 수 있습니다. ?의 참고 자료에서 이미지·장단점·적합한 상황을 살펴보세요.
- **로그인과 역할은 한곳에서**: 03 사용자·환경에서 ‘로그인 없이 사용’ 또는 ‘로그인 필요’를 고릅니다. 필요한 경우 자체 이메일·아이디 로그인, 인증 링크·번호, 카카오·네이버·Google·Apple 등을 복수 선택합니다. 로그인 제공과 모든 화면의 로그인 필수 여부는 다릅니다. 비로그인 사용자·로그인 사용자·관리자를 추가하거나 역할 이름을 직접 정한 뒤 05에서 각 화면의 이용 역할을 고릅니다. 역할 선택을 펼쳐 이름으로 검색하고 여러 항목을 체크할 수 있습니다. 검색은 기존 선택을 지우지 않으며 긴 목록은 내부에서 스크롤합니다. Escape나 목록 바깥 클릭으로 닫습니다. 이름을 바꿔도 화면 연결은 유지됩니다. 역할을 삭제하면 연결된 화면에 확인 안내가 나오며, 오래된 연결을 해제하고 다른 역할을 고를 수 있습니다. 빈 역할 선택은 전체 공개가 아니라 미정입니다.
- **동작을 내 말로 정리**: “검색어를 적고 찾기를 누르면 결과를 보여 주세요. 실패하면 입력한 검색어는 유지해 주세요”처럼 씁니다. AI 요청문은 자연어에 포함된 기능·필드·권한·예외를 해당 요소에 연결해 정리하도록 안내합니다. 기존 구조화된 동작과 충돌하면 확인할 질문으로 남깁니다.
- **화면 추천 범위 구분**: 화면 목록 추천은 필요한 화면 이름·역할·이동 흐름을, 개별 화면의 구성 추천은 그 화면의 요소·배치·표시 정보·오류 안내·휴대폰 구성을 요청합니다. 이미 적은 자연어와 배치는 유지할 조건으로 전달합니다. 이전에 요청한 요소·동작·권한별 추천도 원래 대상과 함께 보존됩니다. 이 사이트가 AI를 자동 실행하는 것은 아니며 초안에서 ‘AI와 기획 다듬기 · 복사’로 전달합니다.
- **참고 자료 정리**: URL을 한 줄씩 추가하거나 여러 줄로 붙여 넣고 참고할 부분을 기록합니다. 주소를 입력해도 사이트 내용을 자동으로 열람하거나 분석하지 않습니다.
- **답변·선택 이유 기록**: 질문·개별 화면에 선택 이유를 남길 수 있으며, 요소의 이유는 용도 설명에 함께 적어도 됩니다. 기존 기능·상세 요소의 선택 이유도 보존합니다. 초안은 해당 대상 아래에 이유를 붙여 다른 항목과 섞이지 않게 표시합니다. 답변과 별도로 자동 저장되며 기획 초안과 백업에도 포함됩니다. 기획 초안에서는 질문 제목과 답변을 누르면 해당 작성 항목으로 바로 이동할 수 있습니다. Markdown과 AI 전달문은 같은 질문 아래에 두 내용을 구분해 담습니다.
- **질문에 맞는 추천 요청과 직접 입력**: 대안을 비교할 수 있는 질문에만 ‘AI에 추천 요청’을 제공합니다. 목록 밖 답변이 가능한 질문은 ‘직접 입력’을 선택하면 후속 입력란이 나타납니다. 추천 요청은 기존 답변을 지우지 않고 AI 전달문에 함께 담깁니다.
- **여러 프로젝트 관리**: 같은 브라우저에서 프로젝트를 만들고 전환하며 이름 변경, 개별·전체 백업, 백업 가져오기를 할 수 있습니다. 프로젝트별 답변과 작성 위치를 따로 보관합니다.
- **PC·모바일 작성 환경**: PC에서는 사이드바로, 모바일에서는 ‘프로젝트·목차’ 버튼으로 단계를 이동합니다. 백업 버튼은 새 프로젝트 아래에, 기획 초안 버튼은 단계 목록 아래에 배치합니다. 모바일에서는 프로젝트 메뉴에서 백업을 관리하고 하단 고정 버튼으로 현재까지 작성한 초안을 확인합니다. 초안에서 돌아오면 작성하던 위치를 유지합니다. 브라우저 저장 상태는 프로젝트 영역의 백업 버튼 아래에 표시하며 눌러 저장 안내를 볼 수 있습니다. 초안 화면 상단의 작업 버튼 영역에서 작성으로 돌아갈 수 있습니다. 모바일에서는 작업 버튼도 문서와 함께 스크롤되어 큰 글자로 읽을 때 본문을 가리지 않습니다.

## 기획 초안에서 화면 설정 읽기

각 화면의 **요소 배치 구조**에서 상단·본문 등의 위치와 요소 안에 다른 요소가 들어가는 관계를 확인합니다. 아래의 요소별 설정에는 포함 대상, 같은 위치 안의 순서, 너비와 직접 적은 내용이 연결됩니다. 너비는 부모 요소나 배치 영역에 대한 상대 크기이며 조절한 최소 높이도 함께 전달합니다. 실제 제품의 크기를 확정한 값은 아닙니다.

화면·요소·입력 항목·동작에는 문서 안에서 구분할 번호를 붙입니다. 예를 들어 `[S01-E03-P01]`은 첫 화면의 세 번째 요소에 속한 첫 항목입니다. 요소 번호는 식별용이며 실제 배치 순서는 배치 구조와 순서 항목에서 확인합니다. 이름이 같은 요소도 번호로 구분합니다. 폼 항목은 이름·입력 방식·필수 여부·선택지·설명을, 동작은 실행 조건·기능·결과·다음 화면·오류 대응을 각각 한 묶음으로 보여 줍니다.

개별 화면에서 가져온 공통 요소는 **설정 원본**의 번호를 따라가면 공통 화면의 세부 설정을 확인할 수 있습니다. 개별 화면에 같은 종류의 요소를 따로 추가한 경우에는 공통 요소 대신 해당 화면의 설정을 사용한다고 표시합니다. 빈 세부 항목은 미정이며 숨긴 요소는 현재 초안에서 제외합니다.

초안 미리보기·Markdown 내려받기·AI 요청문 복사는 같은 문서 내용을 사용합니다. 복사할 때는 포함 관계와 입력 내용을 유지하고 빈 내용을 임의로 확정하지 않도록 AI 지침을 덧붙입니다. 외부 AI가 만든 문서는 원래 입력과 비교해 검토하세요. 내보내기는 저장된 답변을 바꾸지 않습니다.

## 진행률은 어떻게 계산하나요?

사이드바에 전체 **작성 현황(%)과 막대**, `질문 25개 중 3개 작성` 형태의 요약을 표시합니다. 각 대항목 옆의 `1/4`는 **작성한 질문 1개 / 현재 해당하는 질문 4개**라는 뜻입니다. 모바일 상단에서도 진행률을 확인할 수 있습니다.

- 현재 답변 조건에 해당하는 질문을 세며, 선택 사항인 마무리 메모는 제외합니다. 후속 질문이 나타나거나 숨겨지면 전체 수와 대항목별 수가 함께 바뀝니다. 질문이 늘면 작성 중에도 비율이 내려갈 수 있습니다.
- 답변이 있는 질문을 세며, 이전 일반 선택 질문에서 직접 고른 ‘아직 미정’도 기존과 같이 기록한 답변으로 봅니다. 기능·화면 같은 반복 목록은 카드 수와 관계없이 질문 하나입니다.
- 목록의 일부 내용만 입력해도 작성한 질문으로 셉니다. 기능 후보를 추가하면 기본 이름이 들어가므로 기능 질문이 작성된 것으로 계산됩니다. 반면 빈 카드나 예전 기능 카드의 ‘아직 미정’ 우선순위만으로는 작성 수가 늘지 않습니다.
- 06 마무리 메모 옆에는 질문 수 대신 ‘선택’을 표시합니다. 작성하거나 비워 두어도 진행률은 같고, 기능 우선순위를 다시 검토하는 별도 질문은 없습니다.
- 질문 전체에 남긴 선택 이유나 AI 추천 요청만으로는 작성 수에 더하지 않습니다. 조건에서 숨겨진 질문도 계산에서 제외합니다.

진행률은 **입력 현황**입니다. 100%가 기획의 완성도나 개발 준비 완료를 뜻하지는 않습니다. 답변을 바꾸거나 새로고침하면 저장된 프로젝트를 기준으로 다시 계산합니다.
