# 사용 가이드

[프로젝트 안내·문서 목차](../README.md) · [저장과 백업](storage-and-backup.md)

서비스를 처음 사용하거나 질문 흐름·기획 초안·AI 전달문·진행률의 동작을 확인할 때 읽습니다. 화면 크기와 스타일 기준은 [UI 기준](ui-guidelines.md)에서 관리합니다.

## 무엇을 만들 수 있나요?

1차 목표는 **아이디어를 구체화하는 데 필요한 정보를 정리하는 것**입니다. 필요한 기능과 화면을 연결하고, 처음 만들 범위와 확인할 일을 담은 기획 초안을 만듭니다. 이 초안을 사람 또는 AI와 함께 검토하며 요구사항을 보완할 수 있습니다.

| 결과물 | 담기는 내용 | 사용하는 방법 |
| --- | --- | --- |
| 서비스 기획 초안 | 입력한 답변, 기능·화면 연결, 선택 이유, 미정 사항 | 화면에서 확인하거나 Markdown 파일로 내려받기 |
| AI에게 전달할 요청문 | 기획 초안과 보완 지침, 비교·추천을 요청한 질문 | ‘AI와 기획 다듬기 · 복사’ 후 원하는 AI 대화에 붙여 넣기 |
| 프로젝트 백업 | 답변·메모·추천 요청·작성 단계 등 프로젝트 기록 | JSON 파일로 보관하고 ‘백업 불러오기’로 불러오기 |

사이트에서 AI를 자동 실행하거나 코드를 생성하지 않습니다. 기술 스택도 자동 확정하지 않습니다. AI 전달문은 바로 개발하기보다 빠진 정보와 모순을 확인하고 기획을 보완하도록 안내합니다. 브라우저에서 복사가 허용되지 않으면 요청문을 Markdown 파일로 내려받습니다.

## 시작 안내

첫 화면에서 회원가입 없이 시작할 수 있다는 점, 답변의 브라우저 저장, 직접 선택하는 AI 공유, 파일 백업을 확인할 수 있습니다. 오른쪽 가상 예시는 한 줄 아이디어가 문제·사용자·기능과 화면 흐름으로 정리되는 모습을 보여 줍니다. 화면 그림은 설명용이며 내 답변에 추가되거나 자동 생성되는 결과가 아닙니다.

처음 방문하면 **00 시작 안내**에서 아이디어가 기획 초안으로 정리되는 예시를 바로 볼 수 있습니다. ‘바로 시작하기’로 01 단계에 진입하거나, **‘사용 가이드 자세히 보기’**를 펼쳐 프로젝트 준비 → 질문 작성 → 초안 확인 → AI 요청문 복사 → 외부 AI와 보완 → 백업·이어쓰기의 6단계를 화면 예시와 함께 따라갈 수 있습니다. 실제 버튼 이름, PC·모바일에서의 위치, 프로젝트 관리, 복원용 JSON 백업과 공유용 기획 초안의 차이를 안내합니다. 예시는 가상 프로젝트이며 내 답변에 추가되지 않습니다.

사이트 링크를 열거나 새로고침하면 기존 작성 여부와 관계없이 **00 시작 안내**를 먼저 보여 줍니다. 저장된 프로젝트·답변·메모·작성 단계는 그대로 보존합니다. ‘바로 시작하기’를 누르면 01로 이동하고, 목차에서 원하는 단계로 바로 이동할 수도 있습니다. 서비스 안에서 프로젝트를 전환하면 해당 프로젝트의 마지막 작성 단계가 열리며, 새 프로젝트는 01부터 시작합니다. 안내는 상단 로고나 왼쪽 목차에서 언제든 다시 열 수 있으며 질문 수와 진행률에는 포함되지 않습니다.

## 9단계 작성 흐름

순서대로 작성하거나 왼쪽 목차에서 필요한 단계로 이동할 수 있습니다. 모든 질문을 한 번에 채울 필요는 없습니다.

| 단계 | 주제 | 정리하는 내용 |
| --- | --- | --- |
| 01 | 아이디어 소개 | 프로젝트 이름, 누구에게 무엇을 제공할지 |
| 02 | 문제와 기존 방법 | 불편한 상황, 현재 해결 방식, 바라는 변화 |
| 03 | 사용할 사람과 환경 | 첫 사용자, 이용 목적과 상황, 기기와 이용 방식 |
| 04 | 필요한 기능 | 기능 후보, 기능별 사용자·기대 결과·우선순위, 상황별 선택과 직접 입력 |
| 05 | 대표 이용 과정 | 시작부터 결과까지의 순서, 예외·실패 시 경험 |
| 06 | 로그인과 사용자 구분 | 로그인 범위와 방법, 가입 조건, 계정 관리, 역할별 권한 |
| 07 | 참고 서비스와 디자인 방향 | 참고 URL과 참고할 부분, 화면 분위기, 기존 브랜드 자료 |
| 08 | 화면 구성 | 화면 목적, 연결할 기능, UI 요소, 빈 화면·오류·모바일 경험 |
| 09 | 첫 버전 정리 | 기능별 출시 범위 검토, 제외할 일, 아이디어 검증과 남은 질문 |

예약·결제·파일·위치·AI 등의 후속 질문은 관련 기능이나 답변을 선택했을 때 나타납니다. 새 상황별 질문은 쉬운 선택지와 ‘직접 입력’, ‘아직 모르겠어요’를 제공하고, 직접 입력란이나 취소 기한 등 추가 질문은 해당 선택에만 표시합니다. 이전 자유 입력 답변과 저장 정보는 작성된 내용이 있을 때 보존하여 표시합니다. 조건이 바뀌어 숨겨진 답변은 보관하되 현재 기획 초안에서는 제외합니다.

## 주요 기능

- **기능을 구체화하는 카드**: 검색, 예약, 알림, 결제 등 후보에서 필요한 기능을 추가하거나 직접 만듭니다. 같은 유형의 기능을 여러 개 만들고 실제 이름·사용자·기대 결과를 적을 수 있습니다.
- **기능과 화면 연결**: 대표 이용 순서와 화면에 앞서 만든 기능을 연결합니다. 화면 요소는 화면 틀·이동, 내용 표시, 입력·찾기, 행동 실행, 알림·진행 상태, 보조 화면으로 묶여 있습니다. 필요한 묶음을 펼치면 가상 서비스의 화면 예시를 볼 수 있습니다. 주황색 테두리 안이 해당 요소입니다. 이미지를 누르면 확대된 예시와 설명이 열리고, 아래 체크박스나 이름을 눌러 선택합니다. 모바일에서 더 크게 보려면 ‘이미지 새 탭에서 보기’를 사용하세요. 예시는 역할을 이해하기 위한 것으로, 내 서비스의 디자인을 확정하지 않습니다.
- **화면 요소 구체화**: 선택한 요소마다 이 화면에서의 용도를 적습니다. 입력 양식에는 글·숫자·단일/복수 선택·날짜 등 입력 방식을 여러 개 고를 수 있고, 목록·카드·표에는 전체 표시·페이지 이동·더 보기·무한 스크롤 중 하나를 고를 수 있습니다. 목록에 없는 요소는 이름과 용도를 직접 추가합니다. 세부 선택은 필수가 아니며, 선택을 해제한 기본 요소의 메모·세부 선택은 보관하고 현재 초안에서는 제외합니다. 다시 고르면 복원됩니다. 직접 추가한 요소를 삭제하면 그 이름과 용도도 삭제됩니다.
- **서비스에 맞는 로그인 계획**: 자체 이메일·아이디 로그인, 인증 링크·번호, 카카오·네이버·Google·Apple 등을 비교합니다. 빌드브리프 자체에 로그인하는 기능이 아니라, 만들 서비스의 로그인 방식을 정리하는 질문입니다.
- **화면 추천 범위 구분**: 화면 단계 맨 위의 ‘필요한 화면 목록을 AI에 추천 요청’은 앞서 적은 사용자·기능·이용 과정을 바탕으로 화면 이름·역할·이동 흐름을 요청합니다. 각 화면 안의 ‘이 화면의 구성을 AI에 추천 요청’은 그 화면에 필요한 요소·배치·표시할 정보·빈 화면과 오류 안내·휴대폰 구성을 요청합니다. 화면의 목적과 기능을 적고 나머지는 비워 두어도 됩니다. 직접 선택하거나 적은 내용은 유지할 조건으로 전달하고, 추천이 필요한 화면만 초안과 AI 요청문에 번호로 연결합니다. 추천 요청만으로 작성 진행률이 올라가거나 AI가 자동 실행되지는 않습니다. 기획 초안에서 ‘AI와 기획 다듬기 · 복사’를 눌러 원하는 AI 대화에 붙여 넣으세요.
- **참고 자료 정리**: URL을 한 줄씩 추가하거나 여러 줄로 붙여 넣고 참고할 부분을 기록합니다. 주소를 입력해도 사이트 내용을 자동으로 열람하거나 분석하지 않습니다.
- **답변·선택 이유 기록**: 질문 아래 펼침 영역의 빈 입력란에 판단 근거를 자유롭게 남깁니다. 답변과 별도로 자동 저장되며 기획 초안과 백업에도 포함됩니다. 기획 초안에서는 질문별로 답변과 선택 이유를 한 묶음으로 표시하고, Markdown과 AI 전달문도 같은 질문 아래에 두 내용을 구분해 담습니다.
- **질문에 맞는 추천 요청과 직접 입력**: 대안을 비교할 수 있는 질문에만 ‘AI에 추천 요청’을 제공합니다. 목록 밖 답변이 가능한 질문은 ‘직접 입력’을 선택하면 후속 입력란이 나타납니다. 추천 요청은 기존 답변을 지우지 않고 AI 전달문에 함께 담깁니다.
- **여러 프로젝트 관리**: 같은 브라우저에서 프로젝트를 만들고 전환하며 이름 변경, 개별·전체 백업, 백업 가져오기를 할 수 있습니다. 프로젝트별 답변과 작성 위치를 따로 보관합니다.
- **PC·모바일 작성 환경**: PC에서는 사이드바로, 모바일에서는 ‘프로젝트·목차’ 버튼으로 단계를 이동합니다. 백업 버튼은 새 프로젝트 아래에, 기획 초안 버튼은 단계 목록 아래에 배치합니다. 모바일에서는 프로젝트 메뉴에서 백업을 관리하고 하단 고정 버튼으로 현재까지 작성한 초안을 확인합니다. 초안에서 돌아오면 작성하던 위치를 유지합니다. 브라우저 저장 상태는 프로젝트 영역의 백업 버튼 아래에 표시하며 눌러 저장 안내를 볼 수 있습니다. 초안 화면 상단의 작업 버튼 영역에서 작성으로 돌아갈 수 있습니다. 모바일에서는 작업 버튼도 문서와 함께 스크롤되어 큰 글자로 읽을 때 본문을 가리지 않습니다.

## 진행률은 어떻게 계산하나요?

사이드바에 전체 **작성 현황(%)과 막대**, `질문 25개 중 3개 작성` 형태의 요약을 표시합니다. 각 대항목 옆의 `1/4`는 **작성한 질문 1개 / 현재 해당하는 질문 4개**라는 뜻입니다. 모바일 상단에서도 진행률을 확인할 수 있습니다.

- 9단계 전체에서 현재 답변 조건에 해당하는 질문만 셉니다. 후속 질문이 나타나거나 숨겨지면 전체 수와 대항목별 수가 함께 바뀝니다. 질문이 늘면 작성 중에도 비율이 내려갈 수 있습니다.
- 답변이 있는 질문을 세며, 일반 선택 질문에서 직접 고른 ‘아직 미정’도 기록한 답변으로 봅니다. 기능·화면 같은 반복 목록은 카드 수와 관계없이 질문 하나입니다.
- 목록의 일부 내용만 입력해도 작성한 질문으로 셉니다. 기능 후보를 추가하면 기본 이름이 들어가므로 기능 질문이 작성된 것으로 계산됩니다. 반면 빈 카드나 기능 카드의 자동 ‘아직 미정’ 우선순위만으로는 작성 수가 늘지 않습니다.
- 첫 버전의 기능 우선순위 검토는 기능을 하나 이상 추가하고 모든 기능을 ‘첫 버전에 필요’ 또는 ‘나중에’로 정했을 때 반영합니다.
- 선택 이유 메모나 AI 추천 요청만 남긴 경우는 작성 수에 더하지 않습니다. 조건에서 숨겨진 질문도 계산에서 제외합니다.

진행률은 **입력 현황**입니다. 100%가 기획의 완성도나 개발 준비 완료를 뜻하지는 않습니다. 답변을 바꾸거나 새로고침하면 저장된 프로젝트를 기준으로 다시 계산합니다.
