# 사용 가이드

[프로젝트 안내·문서 목차](../README.md) · [저장과 백업](storage-and-backup.md)

서비스를 처음 사용하거나 질문 흐름·기획 초안·AI 전달문·진행률의 동작을 확인할 때 읽습니다. 화면 크기와 스타일 기준은 [UI 기준](ui-guidelines.md)에서 관리합니다.

## 무엇을 만들 수 있나요?

1차 목표는 **아이디어를 구체화하는 데 필요한 정보를 정리하는 것**입니다. 필요한 기능과 화면을 연결하고, 떠오르는 생각과 궁금한 점을 담은 기획 초안을 만듭니다. 처음 만들 범위와 아이디어를 확인할 방법은 이 초안을 사람 또는 AI와 다듬으며 정할 수 있습니다.

| 결과물 | 담기는 내용 | 사용하는 방법 |
| --- | --- | --- |
| 서비스 기획 초안 | 입력한 답변, 기능·화면 연결, 선택 이유, 미정 사항 | 화면에서 확인하거나 Markdown 파일로 내려받기 |
| AI에게 전달할 요청문 | 기획 초안과 보완 지침, 비교·추천을 요청한 질문 | ‘AI와 기획 다듬기 · 복사’ 후 원하는 AI 대화에 붙여 넣기 |
| 프로젝트 백업 | 답변·메모·추천 요청·작성 단계 등 프로젝트 기록 | JSON 파일로 보관하고 ‘백업 불러오기’로 불러오기 |

사이트에서 AI를 자동 실행하거나 코드를 생성하지 않습니다. 기술 스택도 자동 확정하지 않습니다. AI 전달문은 바로 개발하기보다 빠진 정보와 모순을 확인하고 기획을 보완하도록 안내합니다. 브라우저에서 복사가 허용되지 않으면 요청문을 Markdown 파일로 내려받습니다.

## 시작 안내

첫 화면에서 회원가입 없이 시작할 수 있다는 점, 답변의 브라우저 저장, 직접 선택하는 AI 공유, 파일 백업을 확인할 수 있습니다. 소개 아래의 BEFORE → AFTER에서는 산책 모임·공방 예약·재료로 요리 찾기, 세 가지 아이디어가 서비스 화면과 구체적인 문제·사용자·첫 기능·선택 이유로 정리되는 모습을 볼 수 있습니다. 위쪽의 좌우 버튼을 누르거나 모바일에서 옆으로 밀어 다른 예시를 보세요. 목록에 키보드 초점을 두면 좌우 방향키, Home/End로도 이동할 수 있습니다. 가상 기획과 디자인이며 실제 출시 사례나 내 답변에서 자동 생성된 결과가 아닙니다. 예시를 둘러봐도 내 프로젝트 내용은 바뀌지 않습니다.

처음 방문하면 **00 시작 안내**에서 아이디어가 기획 초안으로 정리되는 예시를 바로 볼 수 있습니다. ‘바로 시작하기’로 01 단계에 진입하거나, **‘사용 가이드 자세히 보기’**를 펼쳐 프로젝트 준비 → 질문 작성 → 초안 확인 → AI 요청문 복사 → 외부 AI와 보완 → 백업·이어쓰기의 6단계를 화면 예시와 함께 따라갈 수 있습니다. 실제 버튼 이름, PC·모바일에서의 위치, 프로젝트 관리, 복원용 JSON 백업과 공유용 기획 초안의 차이를 안내합니다. 예시는 가상 프로젝트이며 내 답변에 추가되지 않습니다.

사이트 링크를 열거나 새로고침하면 기존 작성 여부와 관계없이 **00 시작 안내**를 먼저 보여 줍니다. 저장된 프로젝트·답변·메모·작성 단계는 그대로 보존합니다. ‘바로 시작하기’를 누르면 01로 이동하고, 목차에서 원하는 단계로 바로 이동할 수도 있습니다. 서비스 안에서 프로젝트를 전환하면 해당 프로젝트의 마지막 작성 단계가 열리며, 새 프로젝트는 01부터 시작합니다. 안내는 상단 로고나 왼쪽 목차에서 언제든 다시 열 수 있으며 질문 수와 진행률에는 포함되지 않습니다.

## 6단계 작성 흐름

순서대로 작성하거나 왼쪽 목차에서 필요한 단계로 이동할 수 있습니다. 모든 질문을 한 번에 채울 필요는 없습니다.

| 단계 | 주제 | 정리하는 내용 |
| --- | --- | --- |
| 01 | 아이디어 소개 | 프로젝트 이름, 누구에게 무엇을 제공할지 |
| 02 | 문제와 기존 방법 | 불편한 상황, 현재 해결 방식, 바라는 변화 |
| 03 | 사용할 사람과 환경 | 첫 사용자, 이용 상황·기기, 로그인 여부·방식, 역할 목록 |
| 04 | 참고 서비스와 디자인 방향 | 참고 URL, 화면 분위기, 기존 브랜드 자료 |
| 05 | 화면과 기능 | 기본 공통 화면 → 개별 화면 → 요소 배치 → 기능·동작 |
| 06 | 마무리 메모 | 남기고 싶은 생각이나 궁금한 점 (선택) |

예약·결제·파일·위치·AI 등의 후속 질문은 관련 기능이나 답변을 선택했을 때 나타납니다. 상황별 질문은 실제 답변 후보와 필요한 경우 ‘직접 입력’을 제공하고, 직접 입력란이나 취소 기한 등 추가 질문은 해당 선택에만 표시합니다. 이전 자유 입력 답변과 저장 정보는 작성된 내용이 있을 때 보존하여 표시합니다. 조건이 바뀌어 숨겨진 답변은 보관하되 현재 기획 초안에서는 제외합니다. 새 선택지에 ‘아직 미정’을 일괄로 붙이지 않습니다. 모르면 선택하지 않고 넘어가며, 바꾸려면 ‘선택 지우기’나 드롭다운의 빈 선택을 이용하세요. 이미 저장된 ‘아직 미정’ 답변은 선택 상태로 남겨 다시 고르거나 지울 수 있습니다. 초안은 빈 세부 답변을 반복 표시하지 않고 필요한 확인 사항을 마지막에 모읍니다. 생략된 내용은 확정된 선택을 뜻하지 않습니다.

06의 마무리 메모는 비워 두고 **‘기획 초안 보기’**로 넘어가도 됩니다. 작성한 내용만 초안에 담고, 빈 메모를 미정 질문으로 다시 요구하지 않습니다. 첫 출시 범위와 아이디어의 쓸모를 확인하는 방법은 ‘AI와 기획 다듬기 · 복사’에 후속 제안 요청으로 포함합니다. 이전 질문지에서 작성한 제외 범위·검증 방법·범위 판단 이유는 초안의 ‘이전에 작성한 내용’과 백업에 보존합니다.

## 화면을 구성하는 방법

1. 05 화면·기능에서 **기본 공통 화면**을 먼저 선택합니다. 오른쪽 **요소** 패널에서 상단 바·왼쪽 메뉴 등을 누르면 가운데 화면에 배치됩니다. ? 버튼은 예시와 설명을 열며 답변을 바꾸지 않습니다.
2. 배치한 요소를 선택하고 오른쪽 **설정**에서 용도·위치·너비·순서를 정합니다. PC에서는 요소를 다른 영역이나 요소 앞으로 끌어 옮길 수 있습니다. 키보드·모바일에서는 위치 선택과 앞으로·뒤로 버튼을 사용합니다. 상단·왼쪽·본문·오른쪽·하단·떠 있는 영역으로 나누는 기획용 배치이며 자유 좌표나 픽셀 디자인 편집기는 아닙니다.
3. **+ 새 화면**으로 개별 화면을 만듭니다. 공통 요소는 옅게 표시되며 선택하면 공통 화면으로 이동해 수정합니다. **화면 설정**에서 이름·목적·사용할 역할을 정하고, 공통 틀이 필요 없으면 **기본 공통 화면 사용**을 끕니다. 공통 틀은 각 화면의 접근 권한을 정하지 않습니다.
4. 개별 화면에 필요한 요소를 삽입하고 **기능** 탭 또는 요소 설정의 후보·직접 추가 버튼으로 기능을 붙입니다. 이어서 동작·결과·이동과 오류·예외 대응을 적거나 AI 추천 요청을 남깁니다.
5. 가운데 화면 아래 **이 화면의 선택 이유 (선택)**에 그 화면의 이유를 남깁니다. 공통 화면의 이유는 따로 저장합니다. 전체 화면을 한 번에 설명하는 이유 입력은 제공하지 않으며, 예전 전체 메모는 초안과 백업에 보존합니다.

모바일에서는 요소·기능·설정 패널이 배치 화면 아래에 이어집니다. 화면 선택 탭이 길어지면 좌우로 스크롤합니다. 빈 공통 화면을 열기만 해서는 진행률이 올라가지 않습니다.

개별 화면은 위쪽 이름 옆 **×**로 바로 삭제할 수 있습니다. 확인창에서 삭제할 화면 이름을 확인하세요. 보고 있던 화면을 삭제하면 옆 화면을 보여 주고, 다른 화면을 삭제하면 현재 화면을 유지합니다. 기본 공통 화면에는 삭제 버튼이 없으며, 화면을 삭제해도 연결했던 기능 자체는 남습니다.

## 주요 기능

- **요소에서 기능 추가**: 먼저 화면 요소를 선택합니다. 각 요소의 ‘기능 후보에서 선택’과 ‘직접 추가’는 같은 줄의 동등한 버튼입니다. 후보에서 필요한 기능을 고르거나 직접 이름을 적으면 바로 아래에 동작 입력란이 생깁니다. 만들어 둔 기능은 후보 목록에서 연결할 수 있습니다. 기능이 떠오르지 않으면 그 요소의 ‘기능·동작 AI 추천 요청’을 선택하세요.
- **공유 기능과 기존 기록**: 같은 기능을 여러 요소·화면에 연결할 수 있습니다. 기능 이름·설명은 함께 바뀌고, 각 위치의 동작·결과·오류 대응은 따로 기록합니다. 접힌 카드에서도 기능을 삭제할 수 있으며 삭제 전 확인합니다. 특정 요소에서만 빼려면 ‘이 요소에서 연결 해제’를 사용하세요. 기능 자체와 작성한 동작은 남겨 둡니다. 이전에 화면에만 연결한 기능은 화면 설정의 ‘이전에 작성한 내용 → 기존 화면 기능’에서 요소를 지정할 수 있습니다. 화면 밖에서 실행하는 알림·처리 기능도 별도로 기록할 수 있습니다.
- **화면 요소 구체화**: 선택한 요소마다 이 화면에서의 용도를 적습니다. 폼은 항목 이름·입력 방식·필수 여부·선택지·제한을, 표는 열 이름·보여 줄 내용을 하나씩 추가·순서 변경·삭제할 수 있습니다. 목록·카드의 표시 정보와 버튼의 동작도 정리하고 실행할 기능을 연결합니다. 자연어 설명만 적어도 되며 구조화된 항목과 중복 작성할 필요는 없습니다. 화면 요소 종류마다 한 설정 묶음을 제공하므로 같은 화면의 여러 폼·표를 구분할 때는 현재 자연어 설명에 이름과 내용을 함께 적습니다. 기존 입력 방식 선택은 보존합니다. 또한 목록·카드·표에는 전체 표시·페이지 이동·더 보기·무한 스크롤 중 하나를 고를 수 있습니다. 목록에 없는 요소는 이름과 용도를 직접 추가합니다. 세부 선택은 필수가 아니며, 선택을 해제한 기본 요소의 메모·세부 선택은 보관하고 현재 초안에서는 제외합니다. 다시 고르면 복원됩니다. 직접 추가한 요소를 삭제하면 이름·용도와 그 안의 동작도 삭제됩니다.
- **로그인과 역할은 한곳에서**: 03 사용자·환경에서 ‘로그인 없이 사용’ 또는 ‘로그인 필요’를 고릅니다. 필요한 경우 자체 이메일·아이디 로그인, 인증 링크·번호, 카카오·네이버·Google·Apple 등을 복수 선택합니다. 로그인 제공과 모든 화면의 로그인 필수 여부는 다릅니다. 비로그인 사용자·로그인 사용자·관리자를 추가하거나 역할 이름을 직접 정한 뒤 05에서 각 화면의 이용 역할을 고릅니다. 역할 선택을 펼쳐 이름으로 검색하고 여러 항목을 체크할 수 있습니다. 검색은 기존 선택을 지우지 않으며 긴 목록은 내부에서 스크롤합니다. Escape나 목록 바깥 클릭으로 닫습니다. 이름을 바꿔도 화면 연결은 유지됩니다. 역할을 삭제하면 연결된 화면에 확인 안내가 나오며, 오래된 연결을 해제하고 다른 역할을 고를 수 있습니다. 빈 역할 선택은 전체 공개가 아니라 미정입니다.
- **기능 다음에 동작 정리**: 기능 카드 안에서 실행 시점, 어떻게 동작하는지, 동작 후 화면을 적습니다. 현재 화면 유지·이전 화면으로 돌아가기도 선택할 수 있습니다. 같은 기능에 동작을 여러 개 추가·정렬·삭제할 수 있고, 다른 기능의 동작은 바뀌지 않습니다. 각 동작의 ‘오류·예외 대응 AI 추천 요청’을 선택하거나 ‘오류·예외 직접 적기’를 펼쳐 대응을 남깁니다. 요청은 초안·AI 전달문에서 화면·요소·기능·동작에 연결되며 확정 요구와 구분됩니다. 이전에 작성한 화면 전체 메모·동작은 내용이 있을 때만 화면 설정의 ‘이전에 작성한 내용’에 표시합니다. 이전의 기능 없는 동작은 ‘기존 동작 기록’으로 보존하며 새 화면에 빈 질문을 추가하지 않습니다.
- **화면 추천 범위 구분**: 화면 단계 맨 위의 ‘필요한 화면 목록을 AI에 추천 요청’은 앞서 적은 사용자·기능·이용 과정을 바탕으로 화면 이름·역할·이동 흐름을 요청합니다. 각 화면 안의 ‘화면 구성 AI 추천 요청’은 그 화면에 필요한 요소·배치·표시할 정보·빈 화면과 오류 안내·휴대폰 구성을 요청합니다. 화면의 목적과 기능을 적고 나머지는 비워 두어도 됩니다. 직접 선택하거나 적은 내용은 유지할 조건으로 전달하고, 추천이 필요한 화면만 초안과 AI 요청문에 번호로 연결합니다. 폼 항목, 표의 열, 목록·카드의 표시 정보와 화면·요소별 동작·다음 화면도 따로 추천 요청에 추가할 수 있습니다. 화면 밖 기능의 이용 범위나 기존 기능별 권한 요청도 유지됩니다. 각 요청은 소속 화면·요소 또는 기능의 번호와 함께 전달하며, 이미 적은 내용은 유지할 조건입니다. 추천 요청만으로 작성 진행률이 올라가거나 AI가 자동 실행되지는 않습니다. 기획 초안에서 ‘AI와 기획 다듬기 · 복사’를 눌러 원하는 AI 대화에 붙여 넣으세요.
- **참고 자료 정리**: URL을 한 줄씩 추가하거나 여러 줄로 붙여 넣고 참고할 부분을 기록합니다. 주소를 입력해도 사이트 내용을 자동으로 열람하거나 분석하지 않습니다.
- **답변·선택 이유 기록**: 질문 아래뿐 아니라 개별 화면·기능·상세 요소에도 선택 이유를 남길 수 있습니다. 초안은 해당 대상 아래에 이유를 붙여 다른 항목과 섞이지 않게 표시합니다. 답변과 별도로 자동 저장되며 기획 초안과 백업에도 포함됩니다. 기획 초안에서는 질문별로 답변과 선택 이유를 한 묶음으로 표시하고, Markdown과 AI 전달문도 같은 질문 아래에 두 내용을 구분해 담습니다.
- **질문에 맞는 추천 요청과 직접 입력**: 대안을 비교할 수 있는 질문에만 ‘AI에 추천 요청’을 제공합니다. 목록 밖 답변이 가능한 질문은 ‘직접 입력’을 선택하면 후속 입력란이 나타납니다. 추천 요청은 기존 답변을 지우지 않고 AI 전달문에 함께 담깁니다.
- **여러 프로젝트 관리**: 같은 브라우저에서 프로젝트를 만들고 전환하며 이름 변경, 개별·전체 백업, 백업 가져오기를 할 수 있습니다. 프로젝트별 답변과 작성 위치를 따로 보관합니다.
- **PC·모바일 작성 환경**: PC에서는 사이드바로, 모바일에서는 ‘프로젝트·목차’ 버튼으로 단계를 이동합니다. 백업 버튼은 새 프로젝트 아래에, 기획 초안 버튼은 단계 목록 아래에 배치합니다. 모바일에서는 프로젝트 메뉴에서 백업을 관리하고 하단 고정 버튼으로 현재까지 작성한 초안을 확인합니다. 초안에서 돌아오면 작성하던 위치를 유지합니다. 브라우저 저장 상태는 프로젝트 영역의 백업 버튼 아래에 표시하며 눌러 저장 안내를 볼 수 있습니다. 초안 화면 상단의 작업 버튼 영역에서 작성으로 돌아갈 수 있습니다. 모바일에서는 작업 버튼도 문서와 함께 스크롤되어 큰 글자로 읽을 때 본문을 가리지 않습니다.

## 진행률은 어떻게 계산하나요?

사이드바에 전체 **작성 현황(%)과 막대**, `질문 25개 중 3개 작성` 형태의 요약을 표시합니다. 각 대항목 옆의 `1/4`는 **작성한 질문 1개 / 현재 해당하는 질문 4개**라는 뜻입니다. 모바일 상단에서도 진행률을 확인할 수 있습니다.

- 현재 답변 조건에 해당하는 질문을 세며, 선택 사항인 마무리 메모는 제외합니다. 후속 질문이 나타나거나 숨겨지면 전체 수와 대항목별 수가 함께 바뀝니다. 질문이 늘면 작성 중에도 비율이 내려갈 수 있습니다.
- 답변이 있는 질문을 세며, 이전 일반 선택 질문에서 직접 고른 ‘아직 미정’도 기존과 같이 기록한 답변으로 봅니다. 기능·화면 같은 반복 목록은 카드 수와 관계없이 질문 하나입니다.
- 목록의 일부 내용만 입력해도 작성한 질문으로 셉니다. 기능 후보를 추가하면 기본 이름이 들어가므로 기능 질문이 작성된 것으로 계산됩니다. 반면 빈 카드나 예전 기능 카드의 ‘아직 미정’ 우선순위만으로는 작성 수가 늘지 않습니다.
- 06 마무리 메모 옆에는 질문 수 대신 ‘선택’을 표시합니다. 작성하거나 비워 두어도 진행률은 같고, 기능 우선순위를 다시 검토하는 별도 질문은 없습니다.
- 질문 전체에 남긴 선택 이유나 AI 추천 요청만으로는 작성 수에 더하지 않습니다. 조건에서 숨겨진 질문도 계산에서 제외합니다.

진행률은 **입력 현황**입니다. 100%가 기획의 완성도나 개발 준비 완료를 뜻하지는 않습니다. 답변을 바꾸거나 새로고침하면 저장된 프로젝트를 기준으로 다시 계산합니다.
